Worker + LERP

MediaPipe inference is now running inside a Web Worker. The main thread only grabs a video frame, transfers it as an ImageBitmap, and receives back a tiny landmark payload. This keeps the UI thread free.

The visible cursor is driven by a LERP loop on the main thread at 60–120 Hz. It glides toward the latest target with a factor that scales with distance — small moves are smoothed, big moves snap. That removes micro-shake without adding felt lag.
